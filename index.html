Projects

  • Moxie, Robot Dog Joint Health Check

    Petoi Bittle X · C++ · ESP32 BiBoard · Servos, calibration

    A C++ program for my C++ class that runs from my laptop over USB and tests all 9 of Moxie's servo joints for accuracy, speed, and steadiness. Joints that drift get recalibrated and retested. Worn servos get flagged, since no code can fix those. Each joint ends up rated Pass, Fixed, or Needs New Servo, and Moxie's original settings are restored before she goes back on Dec 21, 2026.

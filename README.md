# J'Lynn Turner, Portfolio

Personal portfolio: projects, experience, competitions and resume.

## Files
- `index.html`: the page content
- `styles.css`: all styles, light and dark themes
- `app.js`: theme toggle, skills drawer, draggable skills button, circuit background
- `fonts/`: Google Sans and Google Sans Flex (SIL Open Font License), self-hosted
- `vercel.json`: security headers
- `JLynn_Turner_Resume.pdf`: resume

## Security
- No third-party requests: fonts and scripts are served from this site only.
- Strict Content-Security-Policy: scripts, styles and fonts load from this site only; no inline code.
- The page cannot be framed by other sites, and it never asks for camera, microphone or location.
- No forms, accounts, cookies or secrets. The theme choice is stored only on the visitor's device.
- Analytics: Vercel Web Analytics (no cookies), served from this site.

Static site, no build step. Deployed on Vercel.
